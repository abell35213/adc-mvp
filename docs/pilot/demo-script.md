# Controlled Pilot Demo Script

1. **Driver scans QR**
   - Show the vehicle QR.
   - Confirm the driver lands in the correct tenant and vehicle flow.
2. **Driver initiates accident protocol**
   - Start the incident.
   - Call out OTP/auth and idempotent incident initiation.
3. **Evidence capture begins**
   - Show guided evidence prompts and safety instructions.
   - Highlight telematics, weather, and media capture triggers.
4. **Safety manager sees the incident**
   - Switch to the web UI.
   - Open the active incident and timeline.
5. **Missing items are flagged**
   - Show missing evidence/task indicators.
   - Explain operator follow-up steps.
6. **Legal defense packet is generated**
   - Request an export.
   - Show status progression to ready.
7. **Export is downloaded**
   - Download the packet.
   - Confirm artifacts and summary sections are present.
8. **Audit trail is reviewed**
   - Show key workflow/audit events.
   - Close with operational guardrails and support path.
