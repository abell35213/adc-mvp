# Pilot Success Metrics

## Core metrics

| Metric | Definition | Target |
| --- | --- | --- |
| Time from incident to packet | Minutes from incident initiation to export ready | <= 15 minutes for standard pilot cases |
| Packet completeness | Percentage of required packet sections populated | >= 95% |
| Missing evidence count | Count of required artifacts still missing at export time | <= 1 per incident |
| Export success rate | Successful completed exports / requested exports | >= 99% |
| Driver protocol completion rate | Driver workflows completed without operator recovery | >= 90% |
| Safety / legal acceptance | Incidents accepted by pilot reviewers without material rework | >= 90% |

## Review cadence

- Review metrics weekly during the controlled pilot.
- Escalate any two-week trend below target.
- Capture remediation actions in the pilot operating review.
